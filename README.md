## 판다마켓

### 기본 요구사항

- [ ] 피그마 디자인에 맞게 페이지 제작
- [ ] UI 라이브러리 없이 진행
- [ ] HTML, CSS 파일을 Netlify로 배포
- [ ] PC 사이즈 기준

### 체크 리스트 (기본)

- [ ] 랜딩 페이지의 url path는 루트로 설정
- [ ] title은 "판다마켓"
- [ ] 화면의 너비가 1920px 이상이면 하늘색 배경은 너비를 꽉 채우고, 내부 요소들의 위치는 고정되며, 여백만 커지도록 함
- [ ] 화면의 너비가 1920px보다 작아질 때, "판다마켓" 로고의 왼쪽 여백 200px "로그인" 버튼의 오른쪽 여백 200px이 유지되고, 화면의 너비가 작아질수록 두 요소 간의 거리가 가까워짐
- [ ] 클릭으로 동작해야 하는 경우, 마우스 커서의 모양을 pointer로 변경
- [ ] "판다마켓" 클릭 시 루트 페이지로 이동
- [ ] "로그인" 버튼 클릭 시 로그인 페이지("/login")로 이동 (빈 페이지)
- [ ] "구경하러가기" 버튼 클릭 시 ("/items")로 이동 (빈 페이지)
- [ ] "Priacy Policy", "FAQ"는 클릭 시 각각 Privacy 페이지("/privacy"), FAQ 페이지("/faq")로 이동 (빈 페이지)
- [ ] 페이스북, 트위터, 유튜브, 인스타그램 아이콘을 클릭 시 각각의 홈페이지로 새로운 창이 열리면서 이동

### 체크 리스트 (심화)

- [ ] 브라우저가 크고 작아짐에 따라 페이지의 요소간 간격, 요소의 크기, font-size 등 모든 크기와 관련된 값이 크고 작아지도록 설정 (상세 설정은 자유)
